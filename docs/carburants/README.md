# Images des carburants

Pastilles des carburants affichées dans les notifications du suivi des pleins
(automatisation déclenchée par un tag NFC dans la voiture) : une image par page de choix.

Nom du fichier : carburants de la page séparés par `-`, suivis de `-plus` quand la page a un bouton « Autres… ».

| Carburant | Couleur |
|---|---|
| SP98 | rouge `#FF5252` |
| SP95 | bleu `#40C4FF` |
| E10 | vert `#69F0AE` |
| E85 | orange `#FF9100` |
| Gazole | jaune `#FFD740` |
| GPL | violet `#B388FF` |
